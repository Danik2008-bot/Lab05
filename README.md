# Лабораторная работа 5. Объектно-ориентированные кошки-мышки

Программа моделирует игру «кошки-мышки» на замкнутом линейном поле из N клеток.
Команды читаются из `ChaseData.txt`, результат записывается в `PursuitLog.txt`
(формат описан в `docs/Project02_Requirements_RU.docx`).

## Структура

| Файл | Что внутри |
|------|-----------|
| `Player.cs` | enum `State` и класс `Player`: имя, позиция, состояние, пройденное расстояние, методы `PlaceAt` и `Move` |
| `Game.cs` | enum `GameState` и класс `Game`: чтение команд `M`, `C`, `P`, определение поимки, вывод таблицы и итогов |
| `Program.cs` | клиентский класс: запускает игру на тестовых данных |
| `data/` | входные файлы `N.ChaseData.txt` и эталонные `N.PursuitLog.txt` |
| `docs/` | текст задания |

## Правила (кратко)

- Первая команда `M` или `C` для игрока задаёт его начальную клетку (это не ход, расстояние не растёт).
- Следующие команды - ходы на целое число клеток, в том числе отрицательное.
- Поле замкнуто в кольцо: при выходе за границу игрок оказывается на другом конце.
- Если после хода кот и мышь в одной клетке, мышь поймана и обработка файла прекращается.

## Запуск

Нужен [.NET SDK](https://dotnet.microsoft.com/download) (в `CatAndMouse.csproj` указан `net8.0`,
при необходимости замените на установленную версию).

```
dotnet run
```

Программа прогонит три теста, запишет результаты в папку `out/` и выведет `Test N: OK`,
если файл совпал с эталоном.

Свои файлы:

```
dotnet run -- путь/к/ChaseData.txt путь/к/PursuitLog.txt
```
